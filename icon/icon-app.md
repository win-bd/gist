# সি প্রোগ্রামের `.exe`-তে কাস্টম আইকন যোগ এবং উইন্ডোজ আইকন ক্যাশ ফিক্স করার সম্পূর্ণ গাইড

উইন্ডোজ প্ল্যাটফর্মে C বা C++ দিয়ে কোনো এক্সিকিউটেবল (`.exe`) তৈরি করার পর উইন্ডোজ রিসোর্স ফাইল (`.rc`) যোগ করলেও অনেক সময় ফাইল এক্সপ্লোরারে কাস্টম আইকন আপডেট হতে চায় না। উইন্ডোজ এক্সপ্লোরারের নিজস্ব মেমোরি ডাটাবেসে পুরনো আইকন ক্যাশ (Icon Cache) লক হয়ে থাকার কারণে এটি ঘটে।

নিচে আইকন তৈরি, রিসোর্স লিঙ্কিং এবং উইন্ডোজ ক্যাশ পুরোপুরি রিসেট করার কার্যকর পদ্ধতি দেওয়া হলো।

---

## ধাপ ১: মাল্টি-রেজোলিউশন `.ico` ফাইল প্রস্তুত করা

উইন্ডোজ এক্সপ্লোরারের ভিউ (Small, Medium, Large icons, Taskbar) অনুযায়ী আইকন স্কেলিং ঠিক রাখতে একাধিক সাইজ সংবলিত একক একটি `.ico` কনটেইনার প্রয়োজন।

1. আপনার লোগো বা ডিজাইনের ব্যাকগ্রাউন্ড ট্রান্সপারেন্ট রেখে উচ্চ রেজোলিউশনের একটি `.png` ফাইল তৈরি করুন।
2. কোনো আইকন কনভার্টার টুল (যেমন: `icoconvert.com` বা `magick convert`) ব্যবহার করে ফাইলটি কনভার্ট করুন।
3. কনভার্ট করার সময় অবশ্যই **Multi-size in one ICO** (যেমন: 16×16, 24×24, 32×32, 48×48, 64×64, এবং 256×256) অপশন নিশ্চিত করুন।
4. ফাইলটির নাম দিন `app_icon.ico` এবং এটি আপনার প্রজেক্টের সোর্স ফোল্ডারে রাখুন।

---

## ধাপ ২: উইন্ডোজ রিসোর্স ফাইল (`.rc`) তৈরি ও কম্পাইল

উইন্ডোজ এক্সপ্লোরার এক্সিকিউটেবল ফাইলের ভেতরের রিসোর্স সেকশনে থাকা সর্বনিম্ন সাংখ্যিক আইডি (Numeric ID) বিশিষ্ট আইকনকে ডিফল্ট অ্যাপ্লিকেশন আইকন হিসেবে প্রদর্শন করে।

### ১. রিসোর্স ফাইল তৈরি

প্রজেক্ট ডিরেক্টরিতে `resource.rc` নামে একটি টেক্সট ফাইল তৈরি করে নিচের লাইনটি লিখুন:

```rc
101 ICON "app_icon.ico"

```

### ২. কম্পাইল ও লিঙ্ক করার নিয়ম

* **GCC / MinGW (কমান্ড লাইন):**
প্রথমে `windres` টুল দিয়ে রিসোর্স স্ক্রিপ্টকে অবজেক্ট ফাইলে কম্পাইল করতে হবে, তারপর মূল কোডের সাথে লিঙ্ক করতে হবে:
```bash
windres resource.rc -O coff -o resource.res
gcc main.c resource.res -o MyApp.exe

```


* **CMake প্রজেক্ট (`CMakeLists.txt`):**
সরাসরি সোর্স লিস্টে `.rc` ফাইলটি অন্তর্ভুক্ত করে দিন:
```cmake
add_executable(MyApp main.c resource.rc)

```


* **IDE ব্যবহার করলে (যেমন: Code::Blocks / CLion / Dev-C++):**
প্রজেক্টে `resource.rc` ফাইলটি **Add to Project** করে সম্পূর্ণ প্রজেক্ট **Rebuild** বা **Clean & Build** করুন।

## ধাপ ৩: উইন্ডোজ আইকন ক্যাশ পুরোপুরি রিসেট করা

সঠিকভাবে কম্পাইল করার পরও যদি উইন্ডোজ এক্সপ্লোরারে পুরনো বা ডিফল্ট ব্ল্যাঙ্ক আইকন দেখায়, তবে উইন্ডোজের ক্যাশ ডাটাবেস জোরপূর্বক মুছে ফেলতে হবে।

১. উইন্ডোজের স্টার্ট মেনু থেকে **Command Prompt (cmd)** খুঁজুন এবং **Run as administrator** দিয়ে চালু করুন।

২. নিচের কমান্ডগুলো ক্রমানুসারে রান করুন:

```cmd
:: ১. উইন্ডোজ এক্সপ্লোরার প্রসেস বন্ধ করা (স্ক্রিন ও টাস্কবার সাময়িক অদৃশ্য হবে)
taskkill /f /im explorer.exe

:: ২. লোকাল অ্যাপডাটার আইকন ডাটাবেস ফাইল ডিলিট করা
attrib -h "%localappdata%\IconCache.db"
del /f /q "%localappdata%\IconCache.db"

:: ৩. এক্সপ্লোরার ক্যাশ থাম্বনেইল ও আইকন ফাইলগুলো ডিলিট করা
del /f /q "%localappdata%\Microsoft\Windows\Explorer\iconcache_*"

:: ৪. এক্সপ্লোরার প্রসেস পুনরায় চালু করা
start explorer.exe

```

কমান্ডগুলো এক্সিকিউট হওয়ার সাথে সাথে উইন্ডোজ এক্সপ্লোরার নতুন করে আইকন ইনডেক্স তৈরি করবে এবং আপনার অ্যাপ্লিকেশনের কাস্টম ট্রান্সপারেন্ট আইকনটি নিখুঁতভাবে প্রদর্শিত হবে।
